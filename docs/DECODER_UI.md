# Crash Telemetry Decoder

`Crash_Decoder` is a dependency-free Windows desktop viewer for `crash_telemetry_dump.json` files generated by the recorder.

## Open a dump

```powershell
dotnet run --project src/Crash_Decoder -- C:\path\to\crash_telemetry_dump.json
```

Or launch it with no argument and select a file. The viewer rejects unrecognized schemas, empty dumps, absent fields, and non-finite control values rather than guessing at data.

## What it displays

- A shared timeline: yoke X (blue), yoke Y (green), rudder (amber), and throttle (red). Throttle is transformed from `0..1` to the common `-1..1` plot scale only for visualization.
- A chronological table of the raw frame values and first two switch words.
- Capture reason, sample count, duration, and capture time.

The viewer is an offline decoder. It does not infer a root cause or claim that a control movement caused a simulator crash.
